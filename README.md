Project Description

Home Page
The Home page contains a header with a navigation menu (5 pages) and a logo, as well as a footer with navigation links to the main pages (Home, Workshops, and Contact). Both the header and footer include hover effects.

The Home page also features a main image and information about Finger Knitting, as well as a Materials gallery featuring Alize Puffy and Alize Puffy More. The gallery is implemented using Flexbox with a horizontal scrollbar at the bottom. An animation effect is also applied to the gallery.

How It Works
The How It Works page contains a panel with 9 images showing the process step by step, from creating the first loop to completing the finished piece. The layout is implemented using Flexbox.

Workshops
The Workshops page contains 6 workshop cards, created using Flexbox.

Each workshop card includes:

A main workshop image with an animation effect
A gallery of smaller images with animation effects
The workshop title
Additional information
Workshop details
Difficulty level
A Book a Workshop button with a hover effect
Inspiration
The Inspiration page contains introductory information about the page and a gallery of 24 images. The gallery is implemented using CSS Grid and includes animation effects.

Contact
The Contact page contains contact information and a Join Us form. The form includes First Name, Email, and a Get Updates button with a hover effect.

Additional information is provided at the bottom of the page.
